// 02 method

  
Four rules I build by

  
Carbon figures get questioned months after they are filed. These rules are how a number survives that.

  

    
01
Trace every figure
Each number keeps its source and its history: what changed, who approved it, and why.

    
02
Calculate it twice
An independent second method checks the result. If the two disagree, the export stops instead of shipping a wrong number.

    
03
Version the rules
Regulations change. Results stay tied to the rules that produced them, so last year’s figure can still be explained.

    
04
Test before trusting
Automated tests reproduce worked examples, so a change that moves a number is caught before anyone relies on it.
